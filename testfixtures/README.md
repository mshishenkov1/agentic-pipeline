# Синтетические фикстуры

Мини-проекты для проверки скриптов гейтов вне реального прогона. Данные полностью
вымышленные.

- `mono/` — монорепозиторий из двух сервисов (Go + Python) с инфраструктурой:
  зоны по шаблонам, слои тестов, трассируемость, `check_infra`, `check_design`.
- `api/` — контракт OpenAPI для `check_contracts.py` (обратная совместимость).

Скрипты, которым нужен `git diff` (`check_zone_diff.py`, `changed_services.py`),
требуют инициализированного репозитория внутри фикстуры:

```bash
cd testfixtures/mono && git init -q && git add -A && git commit -qm fixture
```

---
description: Ручной прогон фикс-цикла по конкретному багу
argument-hint: <BUG-id, например BUG-003>
---

Прогони фикс-цикл по багу `$ARGUMENTS` (процедура и ограничения — CLAUDE.md, раздел «Фикс-цикл»).

1. Прочитай `bugs/$ARGUMENTS.json`. Если файла нет — покажи список существующих багов и остановись.
2. Если статус `fixed` — сообщи и спроси человека, надо ли переоткрывать. Если `escalated` — спроси, сбрасывать ли счётчик итераций.
3. Проверь, что `failing_test` падает (`commands.test_single` из `pipeline.config.yaml`). Если тест зелёный — баг, возможно, уже исправлен: предложи закрыть.
4. Далее стандартный цикл: `scripts/state.py agent dev` → dev-agent с баг-репортом и спекой → zone-diff → `scripts/state.py agent test` → test-agent на верификацию (падавший тест + полный сьют) → zone-diff → `sync-bugs`.
5. Соблюдай лимит итераций из конфига; при превышении — эскалация со сводкой.
6. В конце покажи статус бага и краткий итог (что изменено, каким тестом закрыто).
